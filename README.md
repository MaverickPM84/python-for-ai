- Learned Git & Github Differences

1. Git = Laptop Scope , Github = Cloud
2. Git = Version History of Code, Github = Store/Share Code
3. Analogy - Git = Google Docs Versions, Github = Google Drive

- Learned Git-Github Lifecycle
1. git-init is used to ask git to start tracking your code, it is a One-time setup when you start a new project
2. When you write a code in a .py or ipynb file, the file exists in your Working Directory in your laptop
3. When you use git add filename.py or git add . , the code is saved in the staging space
4. When you use git commit -m "meaningful message" , you take a snapshot of the code on your laptop
5. When you use git push, the code changes are pushed to the github
6. Always start your day with git pull so that your laptop code is synced with the repo
7. commit + sync on VS code means - commit + pull (if needed) + push

Lifeycle = Code Changes -> add -> commit + meaningful msg -> push
